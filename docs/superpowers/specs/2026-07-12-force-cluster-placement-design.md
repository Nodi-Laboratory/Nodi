# 힘-기반 클러스터 배치 — 유사도-거리 목적함수 × 증분 힘 솔버

날짜: 2026-07-12 (개정: 2026-07-13 — 리프 무겹침 + 주제 분리 간격 확대)
상태: 사용자 승인 완료 (스펙 작성 → 구현 계획 전)
선행: 2026-07-12-embedding-canvas-placement-design.md (서버 권위 좌표·place SSE·canvas_cards)

## 1. 배경과 목표

선행 피처(feature/09)로 좌표 결정을 서버로 이전했으나, 배치 알고리즘이 격자
`nearest_free_cell`의 FX<FY 비대칭 때문에 모든 카드를 한 행(y=40)에 가로로 나열하는
1차원 퇴화를 보였다(실측: 한 세션의 암석·마그마·대기·우주 카드가 전부 y=40, x만 460씩 증가).
유사도 기반 2D 군집이 성립하지 않았다.

**목표:** 임베딩 유사도를 실제 좌표 거리로 매핑해,
- **같은(유사한) 개념끼리는 하나의 중심으로 조밀하게 모여 군집**을 이루고,
- **다른 개념끼리는 능동적으로 멀리 밀려나** 군집 간이 분리되며,
- 카드는 **생성 시점에 배치되면 고정**(기존 카드는 재배치 안 함),
- 카드 크기는 **본문 내용량에 따라 동적**으로 정해지고 배치(충돌)에 반영된다.

**2026-07-13 개정(본 리비전):**
- **리프(영상추천·삽화)도 응답 카드와 절대 겹치지 않는다** — 개념 곁 고정 오프셋 배치가 조밀 군집에서
  다른 카드 위에 얹히던 문제를 나선 무겹침 배치로 해소(§2-5).
- **주제(클러스터)별 분리 간격을 넓힌다** — 다른 개념끼리 더 확실히 떨어지도록 `D_MAX`를 키우고,
  클램프에 잘리지 않게 캔버스 배치 영역을 함께 확장(§2-1, §5).

**설계 원칙:** 하이브리드 —
- **목적함수 = 접근 #1**(앵커드 스트레스 / 거리=유사도): 무엇을 만족할지 정의.
- **솔버 = 접근 #2**(증분 힘-기반 이완, 기존 pin): 어떻게 도달할지.
- 좌표 체계 = **연속 좌표 + 충돌 회피**(격자 폐기).
- 중심점 = **계산용(비가시)**, 창발적 centroid.

## 2. 배치 알고리즘

### 2-1. 목적: 유사도 → 목표 거리

새 카드 n과 각 기존 카드 i의 코사인 유사도 `s_i ∈ [-1,1]`(음수는 0 클램프)에 대해
목표 거리 `d_i = f(s_i)`:

```
f(s) = 0                                if s >= S_MERGE     # 같은 개념 → 중심에 포갬
       D_MAX * ((S_MERGE - s) / (S_MERGE - S_MIN))^GAMMA   if S_MIN <= s < S_MERGE
       D_MAX                            if s < S_MIN        # 다른 개념 → 최대 분리
```

- `S_MERGE`(예 0.80): 이상이면 목표 거리 0 → 동일 군집 중심으로 수렴("완전히 같게").
- `S_MIN`(0.20): 이하면 최대 거리 `D_MAX`로 능동 분리("멀게"). 낮출수록 인력 구간이
  넓어져 중간 유사 개념이 더 조밀해진다.
- `GAMMA`(4.0): 클수록 중간 유사도 거리가 급격히 작아져 **군집이 조밀**해지고, S_MIN 근처에서만
  급상승해 **군집 간 분리는 확실**하다. (초기 2.0에서 상향 튜닝 — E2E에서 유사군집 상호거리
  814→550px, 충돌 하한 ~510px에 근접.)
- `D_MAX`: 캔버스 스케일 상수(1500px — 주제별 클러스터 분리 간격). 값을 키우면 다른 주제가
  더 멀리 밀린다. 클램프에 잘려 분리가 무효화되지 않도록 캔버스 배치 영역(CANVAS 3200×2200)을
  함께 넓힌다(특히 세로가 타이트했음). 파라미터는 §5.

### 2-2. 솔버: 증분 힘 이완 (기존 pin)

새 카드 위치 `p`(2 미지수)만 최적화. 기존 카드 위치는 고정.

- **초기값**: 유사도 가중 무게중심 `p0 = Σ softmax(s_i / τ) · p_i` (유사 카드 없으면 §2-4 시드).
- **인력**: 각 기존 카드 i에 스프링, rest-length `= d_i`, 힘 `F_attr = k_a · (‖p−p_i‖ − d_i) · û`.
  `d_i=0`인 카드(같은 개념)는 rest-length 0 → 중심으로 강하게 수렴.
- **척력/충돌(AABB)**: 카드를 좌상단 기준 사각형(폭 CARD_W × 높이 h)으로 보고, 두 사각형이
  `MIN_GAP` 포함 겹치면 **최소이동벡터**(침투 작은 축)로 밀어낸다. 외접원이 아니라 실제 사각형이라
  **가변 높이에서도 무겹침을 정확히** 판정한다(외접원은 좌상단-중심 불일치로 가변 높이 시 겹칠 수
  있었다). 같은 개념(d=0)도 이 반발 하한 때문에 포개지지 않고 최소 간격의 조밀 군집을 형성.
- **무겹침 보장**: 힘 이완 후에도 남은 겹침은 (1) 하드 분리 반복, (2) 그래도 남으면 힘이 정한
  위치에서 **나선 탐색**으로 가장 가까운 빈 자리를 찾아 제거 → 캔버스에 공간이 있는 한 카드는
  절대 겹치지 않는다(결정론).
- **쿨링**: 스텝마다 변위에 온도 `T_t = T_0 · α^t`(α<1) 곱, `ITERS`회 반복(예 200).
- **결정론**: 고정 `ITERS` + 고정 초기값 + 난수 미사용 → 같은 입력이면 같은 좌표.
  (Math.random 없음. 초기값이 결정적이므로 시드 불필요.)
- **효율**: 세션당 카드 수는 수십~수백. 이웃 질의는 카드 수 증가 시 quadtree(Barnes-Hut)로
  O(N log N)화(초기 구현은 O(N²) 허용, N 임계 초과 시 최적화 — §5 상수로 게이트).

### 2-3. 두 단계 배치 (스트리밍 + 카드 크기 연동)

1. **스트리밍 첫 @concept**: 로딩 카드를 초기 추정 위치 `p0`(기본 크기 가정)에 즉시 표시
   → `place{concept_index, x, y}` (선행 피처의 SSE 재사용). 항상 표시(로딩 UI).
2. **본문 스트리밍**: 카드가 내용에 따라 성장(프론트 렌더 — 위치는 유지).
3. **done**: 최종 본문으로 **실제 카드 크기** 확정 → 그 크기를 반영해 §2-2 이완을 최종 실행
   → 확정 좌표를 **settle** 이벤트로 전송(신규 SSE `place` 재사용, is_final 플래그) →
   카드가 CSS 트랜지션으로 최종 자리에 안착(주변과 겹치지 않게 밀림). 좌표·크기 영속.

동일 답변에 개념이 2개 이상이면 각 개념을 도착 순서대로 위 절차에 넣되, 같은 답변 내 이미
배치된 개념도 pin 대상에 포함(세션 전체 pin 집합에 합류).

### 2-4. 경계 케이스

- **첫 카드 / 유사 카드 없음**: 인력 없음 → 캔버스 중앙(또는 기존 군집에서 가장 먼 빈 영역)에 시드.
- **degraded**(Qdrant/Upstage 다운): 유사도 계산 불가 → 초기 추정 없이 빈 영역 시드 좌표로
  폴백. near/place는 항상 좌표 반환(로딩 카드 상시 표시 규약 유지).

### 2-5. 리프(영상/삽화) 무겹침 배치

개념 카드 곁에는 EBS 추천 **영상(VideoNode, 340px)**·**삽화(ArtNode, 220px)** 리프 노드가 붙는다.
이들은 서버 힘 솔버의 배치 대상이 아니라 **프론트에서** 앵커 개념 좌표를 기준으로 놓인다. 기존에는
`앵커.x + (CARD_W+MARGIN), 앵커.y + 순번·offset`의 **고정 오프셋**이라, 힘 솔버가 카드를 조밀하게
군집시키면 그 자리에 **다른 응답 카드가 겹쳐** 렌더됐다(요구 위반).

- **선호 위치**: 앵커 카드 오른쪽 스택(기존 오프셋)을 그대로 "선호"로 둔다(시각적 연관 유지).
- **무겹침 확정**: 모든 개념 카드(실측 높이 = 서버 `h` 또는 본문 줄 수 폴백, ConceptCard와 동일
  계산)와 **이미 놓인 리프**를 AABB 장애물로 삼아, 선호 위치가 겹치면 §2-2와 동일한 **나선 탐색**으로
  `MIN_GAP` 여백을 둔 가장 가까운 빈 자리를 찾는다(서버 `_first_free_position` 이식, 결정론).
- **적용 지점(양쪽 동일)**: (1) 라이브 스폰(`useConceptStream` retrieve 직후), (2) 재수화
  (저장 노드 → 리프 재생성). 재수화 시점은 모든 카드 좌표가 확정돼 있어 무겹침이 완전히 결정된다.
- **캔버스 무한 팬**이므로 경계 클램프는 없다(카드 솔버와 달리).

## 3. 카드 크기 동적화

- 크기 지표 `L` = 본문 렌더 길이(개념 블록의 본문 줄 수, 보조로 글자 수).
- 카드 크기 = 폭 고정(기존 420) 가정 하 **높이**를 `clamp(H_MIN + L·H_PER_LINE, H_MIN, H_MAX)`로.
  (폭도 스케일하려면 §5에서 별도 상수. 초기 구현은 높이만.)
- 충돌 반경 = 카드 바운딩 박스의 외접원/사각 반경. 힘 솔버 척력·MIN_GAP 입력.
- 크기는 **done 시점 내용으로 확정 후 고정**(위치와 함께 "생성 시 고정"). 배치 후 리사이즈/호버
  확대는 범위 아님.
- 서버는 done 시 본문 길이로 `L`을 산출해 크기를 추정(렌더 실측 아님 — 근사면 충분). `L`(또는
  산출 높이)을 canvas_cards·attachments에 저장해 리로드 재현.

## 4. 데이터·영속·계약

### canvas_cards (선행 피처 컬렉션 확장)
- payload에 `size_h`(또는 `body_len L`) 추가. `x,y`는 연속 실수(격자 셀 아님).
- point id·필터(owner+session) 규약은 선행 피처 그대로.

### nodes.attachments.canvas.concepts (확장)
- `[{i, x, y, h}]` — 좌표에 카드 높이 h 추가. 리플레이는 저장 좌표·크기 그대로 렌더(재계산 없음).

### SSE / 라우터
- `place{concept_index, x, y, is_final}`(연속값 float). 스트리밍 첫 배치는 `is_final=false`
  (초기 추정 위치), done settle은 **같은 place 이벤트를 `is_final=true`로 재전송**(신규 이벤트
  타입 추가 아님). 프론트는 is_final=true 수신 시 해당 개념을 확정 좌표로 트랜지션.
- `/retrieve` near: 첫 카드 초기 추정 좌표(연속). 응답 계약은 선행 피처 유지, 좌표만 연속.
- done 훅(단일 writer): concepts 좌표+크기 + ebs/art를 attachments.canvas에 통합 저장(선행 피처
  단일 writer 유지).

## 5. 파라미터 (초기값, admin 노출 아님 — config)

| 이름 | 초기값 | 의미 |
|---|---|---|
| `S_MERGE` | 0.80 | 이상이면 목표거리 0(동일 군집) |
| `S_MIN` | 0.20 | 이하면 최대거리(완전 분리); 낮을수록 조밀 |
| `GAMMA` | 4.0 | 중간 유사도 거리 곡률↑ = 군집 조밀화 |
| `D_MAX` | 1500 | 최대 목표 거리(px) — 주제(클러스터)간 분리 간격 |
| `CANVAS_W`/`CANVAS_H` | 3200/2200 | 배치 영역(D_MAX 클램프 방지 위해 D_MAX와 동반 확장) |
| `MIN_GAP` | 24 | 카드 간 최소 간격(px) |
| `K_ATTR` / `K_REP` | 0.1 / 0.9 | 인력/척력 계수 |
| `TAU` | 0.15 | 초기 무게중심 softmax 온도 |
| `ITERS` | 200 | 이완 반복(결정론 고정) |
| `T0` / `ALPHA` | 0.9 / 0.95 | 쿨링 초기온도/감쇠 |
| `H_MIN`/`H_MAX`/`H_PER_LINE` | 160/560/28 | 카드 높이 범위·줄당 증가(px) |
| `QUADTREE_N` | 120 | 카드 수 초과 시 Barnes-Hut 사용 |

## 6. 무엇이 바뀌나

- **백엔드 `canvas_layout.py`**: 격자(FX/FY/cell) → 연속 좌표 힘 솔버로 재작성. `place_new_card(
  new_embedding, existing:[{x,y,h,embedding|sim}], size_h) -> (x,y)` 결정론 함수 + 충돌 해소.
  기존 격자 상수/함수 제거(리프 배치가 참조하면 대체).
- **백엔드 `retrieve.py`**: near = 초기 추정 좌표(가중 무게중심). session 카드 scroll에
  `x,y,h,vector` 포함(유사도 계산 위해 벡터 필요 → canvas_cards with_vectors=True 또는
  질의 임베딩과 저장 벡터 코사인).
- **백엔드 `chat.py`**: place 연속좌표 + done settle 재전송. done 훅에서 본문 길이 `L` 산출·크기
  확정·최종 이완 실행 후 좌표·크기 저장.
- **백엔드 `qdrant_store.py`**: canvas_cards payload `size_h`, scroll에 벡터 포함 옵션.
- **프론트 `ConceptCard`**: 본문 길이 기반 높이(동적), 서버 좌표(연속) 렌더 + settle 트랜지션.
- **프론트 `useConceptStream`/`layout.ts`**: 격자 배치 제거, place/settle 연속좌표 수신.
- **프론트 `leafPlacement.ts`**: 리프(video/art) **무겹침** 배치. 앵커 카드 오른쪽 스택을
  선호 위치로 두되, 모든 개념 카드(실측 높이) + 이미 놓인 리프를 AABB 장애물로 삼아 **나선 탐색**으로
  겹치지 않는 가장 가까운 자리에 배치(서버 `_first_free_position` 이식). 라이브 스폰·재수화 양쪽에서
  동일 적용 → 영상/삽화가 응답 카드와 절대 겹치지 않는다.

## 7. 에러 처리

| 상황 | 동작 |
|---|---|
| Qdrant/Upstage 다운 | degraded → 빈 영역 시드 좌표, near/place 항상 반환(로딩 카드 표시) |
| 벡터 조회 실패 | 유사도 0 취급 → 분리 배치(멀리 시드) |
| done 훅 실패 | 로그만(스트림·저장 무영향, 선행 피처 규약) |
| 카드 수 급증 | QUADTREE_N 초과 시 Barnes-Hut, 아니면 O(N²) |

## 8. 테스트

- **백엔드 유닛(canvas_layout)**:
  - 결정론: 같은 (new_embedding, existing, size) → 같은 (x,y) 반복 일치.
  - 유사 수렴: sim≥S_MERGE 카드 다수 → 새 카드가 그 중심 MIN_GAP 이내로 배치.
  - 비유사 분리: sim<S_MIN → 목표거리 D_MAX 근처(기존 군집에서 멀리).
  - 겹침 없음: 가변 크기 카드들이 MIN_GAP 이상 간격 보장.
  - 시드: 빈 세션/유사 카드 없음 → 시드 좌표.
- **백엔드 유닛(크기)**: 본문 길이 L → 높이 clamp 범위·단조 증가.
- **E2E(Playwright, 기존 하네스)**:
  1. 유사 질문 3연속(예 광합성·세포호흡·엽록체) → **한 중심에 조밀 군집**(상호 거리 작음, y도 분산).
  2. 무관 질문(예 광합성 후 "지진") → 기존 군집에서 **멀리 분리**.
  3. 긴 답변 vs 짧은 답변 → 카드 높이 차이 렌더.
  4. 새로고침 → 저장 좌표·크기로 동일 재현.
  5. degraded(Qdrant 중단) → 로딩 카드 표시 + 시드 배치.
  6. **리프 무겹침(개정)**: EBS/삽화가 붙는 과학 질문 다수 → 영상·삽화 노드가 어떤 응답 카드와도
     겹치지 않음(라이브·재수화 양쪽, AABB 월드좌표 정밀 검출로 0쌍).
  7. **주제 분리(개정)**: 서로 다른 주제 질문 → 카드 중심 최대거리가 이전(D_MAX 1200) 대비 커짐.

## 9. 비범위

- 동일 개념 카드 **병합**(중복 합치기+카운트) — 조밀 군집으로 대체(사용자 확인).
- 배치 후 카드 이동/리사이즈, 호버 확대, 실시간 클라 물리(서버 결정론으로 대체).
- 유저 통합 맵(세션 스코프 유지), 교육과정 태그 분류.
- 리프(video/art) 배치의 정교한 군집화(무겹침 나선 배치까지만 — 개념 곁 선호, 충돌 시 인근 회피).
