# 고정 교과과정 태그 + 카드 추종 SVG 설계

날짜: 2026-07-13
상태: 사용자 승인 완료 (스펙 작성 → 구현 계획 전)
선행: 2026-07-13-frontend-tag-force-layout-design.md (d3-force 태그 레이아웃 — 동적 드리프트를 고정으로 전환)

## 1. 배경과 목표

직전 피처로 카드가 태그별 d3-force 클러스터로 **동적 이동**(노드 수↑→더 분리)한다. 이제 고2 지구과학
교과과정에 맞춰 **태그를 7개로 고정**하고, **태그 위치를 지도에 고정**하며, **SVG(삽화)가 매칭 카드를
따라 이동**하게 한다.

**핵심 결정(승인됨):**
- **7개 고정 태그**: 자유 분류어 폐기, EXAONE 프롬프트로 다음 7개 중 하나만 얻는다.
  1. 해수의 운동과 순환  2. 지구의 형성과 역장  3. 지구 구성 물질과 자원  4. 한반도의 지질
  5. 대기의 운동과 순환  6. 행성의 운동  7. 우리은하와 우주의 구조
- **태그 위치 고정**: 7개 태그 → 지도 고정 앵커(칠각형). 카드는 자기 태그 고정 앵커 주변에 모임(무겹침).
  직전 피처의 "count 비례 동적 분리(태그 드리프트)"는 이 결정으로 폐기.
- **태그 라벨은 카드 있는 태그만** 표시(위치는 고정).
- **SVG = 맵당 1개 대표(최고 스코어)** 가 앵커 카드의 sim 위치를 추종(카드가 움직이면 함께).

## 2. 7개 고정 태그 (EXAONE 프롬프트)

- `CONCEPT_CARD_SYSTEM_PROMPT`의 분류 규칙(현재 "안정적 대분류…")을 아래로 교체:
  - "분류는 반드시 다음 7개 중 하나만 사용한다(정확히 그 문자열): 해수의 운동과 순환 / 지구의 형성과
    역장 / 지구 구성 물질과 자원 / 한반도의 지질 / 대기의 운동과 순환 / 행성의 운동 / 우리은하와 우주의
    구조. 질문에 가장 맞는 하나를 고른다. 새 분류어를 만들지 마라."
- 모델이 7개 밖 값을 내면(방어) 프론트가 `기타`로 폴백.
- 프롬프트에 고2 지구과학 범위임을 함께 명시(범위 밖 질문도 가장 가까운 단원으로 분류하도록 유도).

## 3. 태그 위치 고정 (프론트)

### 3-1. `curriculumTags.ts` (신규 상수)
- 7개 태그 문자열(§1 목록) → **고정 앵커 좌표**. 중앙 `CENTER=(1600,1100)` 기준 칠각형:
  `anchor_i = CENTER + R·(cos θ_i, sin θ_i)`, `θ_i = -π/2 + i·2π/7`, `R=1400`.
- `기타`(폴백) = 중앙(CENTER).
- `tagAnchor(tag): {x,y}` — 7개 중 하나면 그 앵커, 아니면 CENTER. `CURRICULUM_TAGS: string[]`(순서=인덱스).
- **주의**: 이 7개 문자열은 EXAONE 프롬프트(백엔드)와 **정확히 일치**해야 한다(모델 출력 문자열로 매핑).

### 3-2. `useTagLayout` 변경
- 응집 타깃을 **동적 무게중심 → `tagAnchor(node.tag)` 고정 앵커**로. 카드는 자기 태그 고정 앵커로 당겨지고
  `forceCollide`로 무겹침. 태그는 안 움직임. `forceManyBody`는 클러스터 내 균등 분산용으로만 약하게 유지
  (인터-태그 분리는 고정 앵커가 담당).
- **초기 시드**: `tagSeed` 대신(또는 병행) 태그 고정 앵커 근처로 시드 → 즉시 제자리 근처에서 안착.
- **출력 `tagCentroids`**: 이제 **고정 앵커 위치 + count**(동적 무게중심 아님). **카드 1개 이상인 태그만**
  포함 → 마커·미니맵이 자동으로 "카드 있는 태그만, 고정 위치"로 표시.

### 3-3. 마커·미니맵
- `TagMarker`·`ConceptMinimap`은 `tagCentroids`를 그대로 소비 → 변경 없이 고정 앵커·populated-only 반영.

## 4. SVG(삽화) 카드 추종

- 검색·선정은 현행 유지: `/retrieve` 질의 임베딩 vs art 카탈로그(임계 이상) → 맵당 **최고 스코어 1개 대표**.
- 표시 위치: 앵커 카드의 **sim 위치**를 추종(직전 피처 T3의 리프 re-anchor가 이미 앵커 개념 sim 위치로
  오프셋). 카드가 d3-force로 이동하면 SVG도 함께 이동. **본 피처는 이 동작을 검증·견고화**(별도 로직
  추가 최소).
- 영상(EBS)도 동일(단일 대표, 카드 추종) — 현행 유지.

## 5. 데이터 흐름

질문 → EXAONE가 7개 중 하나의 `분류` 반환 → 프론트가 `tagAnchor(분류)` 고정 앵커로 카드를 클러스터
(d3-force, 무겹침) → 카드 있는 태그만 마커/미니맵에 고정 위치로 표시 → SVG(최고 스코어)는 그 카드 곁에서
카드 sim 위치를 추종.

## 6. 에러 처리

| 상황 | 동작 |
|---|---|
| 분류가 7개 밖 | `기타`(중앙 앵커)로 폴백 |
| 태그 0개 | 빈 상태(마커·미니맵 없음) |
| 벡터 매칭 없음 | SVG 없음(현행) |
| 한 태그에 카드 다수 | 고정 앵커 주변 무겹침 클러스터(collide) |

## 7. 테스트

### 7-1. 순수 유닛(node 새너티)
- `tagAnchor`: 7개 태그 각각 서로 다른 고정 좌표(칠각형), `기타`/미지 → CENTER. 결정론.
- 7개 앵커 상호 거리 하한(분리) 확인.

### 7-2. E2E(Playwright)
1. 서로 다른 단원 질문 → 각 태그가 **고정 위치**에 클러스터(재질의해도 태그 위치 불변).
2. 카드 있는 태그만 라벨/미니맵 점 표시.
3. SVG가 카드 이동 시 **함께 이동**(단일 대표 유지).
4. 카드 무겹침. 5. 새로고침 → 고정 앵커로 동일 재현.

## 8. 비범위

- 직전 피처의 count 비례 동적 분리(태그 드리프트) — "태그 고정"으로 폐기(요구).
- 7개 밖 자유 태그 지원(고정 집합만).
- 서버 사문화 배치 코드(tag_anchor/place_by_tag/place emit) 물리 제거 — 별건 후속.
- SVG/영상 검색 파이프라인(임베딩·임계) 변경 — 유지.
- 미니맵/마커 컴포넌트 구조 변경 — 입력(고정 앵커)만 바뀜.
