# 태그별 대화 트리 (D151)

사용자 지시 2026-08-02. 옛 Nodi(`Zanviq/Nodi`)의 노드 트리를 캔버스 v2로
가져오되 단위를 바꾼다.

```
옛 Nodi   세션 하나 = 트리 하나   분기는 컨텍스트를 **줄이려고** 갈랐다
지금      태그 하나 = 트리 하나   컨텍스트는 다 넣고, 트리는 **초점**이다
```

컨텍스트를 자르지 않는 것은 사용자 결정이다 — "그 철학을 적용하지 않아도 된다.
그냥 모든 컨텍스트를 다 붙여도 돼. 대신 AI가 그걸 판단할 수 있도록 해야 해."

## 1. 무엇을 노드로 볼 것인가

**AI가 쓴 개념 카드만** 노드다(`kind='concept' AND source='ai' AND tag IS NOT NULL`).
학생 메모·교과서 도판은 트리에 넣지 않는다.

근거는 요구사항 자체다 — "거미줄처럼 연결선이 너무 많지 않았으면. 마인드맵처럼."
캔버스의 모든 것을 노드로 삼으면 메모 하나가 여러 답에 걸리면서 간선이 곱으로
늘어난다.

## 2. 간선 규칙

저장은 이미 있는 열 하나로 끝난다 — `canvas_items.parent_item_id`. 스키마를
늘리지 않았다.

간선이 성립하는 조건은 셋이고, 셋 다 만족해야 한다:

1. 자식의 `parent_item_id`가 실제로 존재하는 행을 가리킨다
2. 부모와 자식이 **둘 다 노드**다(위 1절)
3. **부모와 자식의 태그가 같다**

3번이 핵심이다. 학생이 카드의 분류를 바꾸면 그 순간 선이 끊기고 그 카드가 새
트리의 뿌리가 된다 — "같은 태그끼리만 선이 연결된다"는 요구가 판정에 그대로
박혀 있어서, 어긋난 상태가 존재할 수 없다.

**간선 수 = 노드 수 − 트리 수.** 부모가 최대 하나이므로 원리적으로 선형이고,
임의의 두 노드를 잇는 경로 자체가 없다. 거미줄이 될 수 없는 이유가 알고리즘의
성질이지 조율의 결과가 아니다.

## 3. 부모를 정하는 규칙 (생성 시점)

턴이 뱉은 카드를 **생성 순서대로** 훑으며:

```
같은 턴에 같은 태그가 또 나왔다  → 직전 카드에 잇는다      (한 줄기)
학생이 고른 노드의 태그와 같다    → 그 노드에서 갈라진다    (분기)
이미 있는 태그다                  → 그 트리의 head 뒤       (이어 붙이기)
처음 보는 태그다                  → 뿌리 (새 트리)
```

`head(tag)` = "가장 최근에 선택했거나 답을 달았던 노드". 학생이 고른 노드가 그
태그에 있으면 그 자리, 없으면 seq가 가장 큰 노드다. 초점은 새로고침에 사라지므로
자연히 후자로 떨어지는데, 그래도 "마지막 답 뒤에 이어 붙는다"는 기대는 지켜진다.

**한 턴의 같은 태그 카드는 형제가 아니라 사슬이다.** 셋을 같은 부모 밑에 형제로
달면 폭이 넓어지고 순서가 안 보인다 — 요구가 "생성 순서대로 연결"이었다.

턴이 끝나면 초점은 **그 태그의 마지막 새 카드**로 옮긴다. 안 옮기면 이어 물을수록
같은 노드에서 형제가 옆으로 쌓이는데, 학생이 기대하는 것은 방금 받은 답 뒤에
이어지는 것이다.

구현: `frontend/src/lib/canvas2/tree.ts` (`assignParents`, `headOf`, `nextFocus`).

### 저장의 함정

같은 턴 안에서 이어 붙인 부모는 **임시 id**다. 그대로 POST하면 아직 없는 행을
가리켜 FK 위반으로 배치 전체가 실패한다. 그래서:

1. `parent_item_id`는 진짜 id만 실어 보낸다
2. 저장 응답으로 임시 id → 진짜 id를 알아낸 뒤 **PATCH로 이어 준다**
3. 서버 행에 우리가 아는 부모를 채워 넣고 나서 로컬에 반영한다

3번을 빠뜨리면 DB에는 있는데 화면에만 선이 없는 상태가 된다(실측으로 잡았다).

## 4. 초점(picked) — 선택과 다른 개념

```
selectedIds   옮기고 지우기 위한 것. 여럿일 수 있다.
pickedId      "이 가지에서 이어 묻는다". 하나뿐이고 AI 개념 카드만 될 수 있다.
```

**끌면 고른 것이 아니다**(사용자 지시). 움직이지 않고 누른 경우에만 잡히고,
배경을 누르면 풀린다. 그래서 카드를 정리하려고 드래그하는 동안 다음 질문이
엉뚱한 가지에 붙는 일이 없다.

입력창의 인용 칩은 초점에서 **파생한다**. 두 곳에 상태를 두면 반드시 어긋난다
(노드를 지웠는데 칩이 남는 식).

## 5. 배치

태그 열은 그대로 두고, 열 **안**에서 트리 순서(깊이 우선)로 놓는다.

- seq 순으로 놓으면 나중에 만든 형제가 이전 가지의 손자보다 위에 와서 선이
  서로를 가로지른다. 트리 순서로 놓으면 가지 하나가 통째로 이어져 내려간다.
- 들여쓰기는 **갈라질 때만** 준다. 첫째 자식은 부모 칸을 물려받고 둘째부터 한 칸
  들어간다. 사슬마다 들여쓰면 카드 열 개에 560px가 밀려 옆 열을 침범한다
  (열 피치 = ITEM_W 460 + COL_GAP 240 = 700).
- 상한 3칸(72×3=216 < 240)이라 어떤 트리도 옆 열을 넘지 않는다.

무겹침 불변식은 그대로다 — 열끼리 x가 안 겹치고 열 안에서 y를 누적한다.

## 6. 지도

축척이 **무엇을 묻고 있는지**를 나눈다.

```
축소(< 1.8배)  태그 하나 = 점 하나          "무엇이 어디에 있나"
확대(≥ 1.8배)  노드 하나 = 점 하나 + 방향선  "무엇에서 무엇이 나왔나"
```

둘을 한 화면에 같이 두면 못 쓴다. 글 20개면 노드 20 + 선 19가 340×250 안에
들어가고 그 위에 태그 점까지 겹친다 — 예전에 "아이템마다 사각형"으로 그렸다가
정확히 그 지적을 받았다("겹치는 부분이 많아서 오히려 보기 힘들다").

- 확대하면 **지금 보고 있는 영역**이 중심이다. 전체 중심에 고정하면 캔버스
  한쪽 끝에서 작업할 때 지도가 엉뚱한 곳을 크게 보여 준다.
- 선 색은 트리(태그)별로 갈리고 화살촉이 방향을 말한다(방향 그래프).
- 이름은 **뿌리에만** 붙인다. 노드마다 달면 글자가 선을 덮는다.
- 고른 노드는 채워서 그린다.

### 캔버스에도 선 보이게 하기

지도 조작 줄의 토글. **기본 켬**(사용자 지시). ConnectorLayer가 같은 저장 키를
보므로 둘이 어긋날 수 없다 — 형제도 부모-자식도 아닌 두 컴포넌트에 prop을
내리는 것보다 이쪽이 안전하다.

트리 간선은 옛 "AI에게 묻기" 선과 다르게 그린다: 가늘게(1.1px, 불투명 0.28),
**라벨 없이**. 카드마다 하나씩이라 "AI 응답" 라벨을 달면 캔버스가 글자보다
선으로 뒤덮인다.

## 7. 컨텍스트

`tree_guide` 블록을 시스템 프롬프트에 추가한다. 태그 목록(`tag_guide`)이
"무엇이 있나"라면 이건 "무엇에서 무엇이 나왔나"다.

```
## [뉴턴의 운동 법칙]  ← 학생이 지금 보고 있는 트리
- 관성의 법칙: 본문…
  - 가속도의 법칙: 본문…
    - 작용 반작용 법칙: 본문…
  - 버스 급출발 시 뒤로 쏠림: 본문…
```

- 세션의 **모든 카드**가 들어간다. 태그별로 한 덩어리, 그 안에서는 부모→자식
  순서다.
- `focus_tag`는 **자르는 값이 아니라 가리키는 값**이다. 프론트가 고른 노드의
  분류를 실어 보내고, 그 트리에만 표시가 붙는다.
- 상한 24,000자. 넘치면 **오래된 트리부터** 버린다 — 최근 대화가 지금 질문과
  가깝다. 무한으로 두면 카드가 수백 개인 세션에서 턴 자체가 죽는다.

### 규칙이 두 언어에 있다

간선 판정이 프론트(`tree.ts`)와 백엔드(`canvas_items._tree_lines`)에 각각
있다. 한쪽만 고치면 학생이 화면에서 본 트리와 AI가 받는 순서가 갈리는데,
**화면에도 로그에도 안 드러난다** — 답이 이상해질 뿐이다. 그래서 양쪽에 같은
케이스의 테스트를 붙였다(프론트 23 + 백엔드 8).

## 8. 검증 (로컬, 실제 브라우저)

- 한 턴 3카드 → `관성 → 가속도 → 작용반작용` 사슬로 저장됨
- 첫 카드를 **클릭**(드래그 아님)하고 이어 물음 → 그 노드에서 새 가지가 갈라져
  `관성 → 버스 급출발 → 젖은 수건 → 책상 위 책` 이 생김. 기존 가지는 그대로.
- 지도: 축소 "태그 묶음" ↔ 확대 "노드 연결" 전환, 노드 6 → 간선 5
- 토글: 캔버스 트리 선 2개가 사라졌다 되살아남
- 프롬프트: `## [뉴턴의 운동 법칙]  ← 학생이 지금 보고 있는 트리`와 들여쓴
  카드 목록이 실린 것을 ai_logs에서 확인
