# 01 · 전체 그림

## 한 줄

교실 학습용 AI 도우미. 학생이 물으면 **개념 카드**가 스트리밍으로 나와 무한
캔버스에 놓이고, 선생님이 올린 수업 자료·교과서를 근거로 답한다.

## 질문 하나가 지나가는 길

학생이 입력창에 치고 Enter를 누르면:

1. **화면** — `useCanvasStream`이 `POST /api/chat/stream`을 연다(SSE).
2. **카탈로그 좁히기** — `ai/catalog.py`가 `(공간 종류, 역할)`과 세션 상태로
   **먼저** 도구를 줄인다. 개인 세션에 학급 도구를 보여 주면 모델이 부르고
   빈 결과로 엉뚱한 답을 한다.
3. **도구 판단** — solar-pro3가 무엇을 부를지 정한다. 인사 한 마디에는 도구가
   아예 안 나가서 임베딩·검색도 안 돈다.
4. **스킬 실행** — 수업 자료 검색·교과서 도판·강의 클립 등. 실패는
   `SkillResult(ok=False)`로 모델에 전해지고 **턴을 죽이지 않는다**.
5. **생성** — 같은 모델이 개념 카드 형식으로 답을 스트리밍한다. 이 단계에는
   도구를 안 준다(두 지시가 섞이면 형식이 무너진다).
6. **화면** — 토큰이 오는 대로 파싱해 카드를 만들고, 배치 엔진이 태그 열에
   앉힌다. 다 받은 **뒤에** 카드를 한 번에 저장한다.

⚠️ 6번의 "다 받은 뒤"가 이 설계의 약한 고리였다 — 그 전에 브라우저가 사라지면
답이 DB에만 남고 카드가 없었다. 지금은 불러올 때 되살린다(D220).

## 왜 이 조합인가

| 고른 것 | 이유 | 대신 버린 것 |
| --- | --- | --- |
| Postgres + RLS | 권한을 **DB가 강제**한다. 앱 코드로 옮기면 창구 하나 빠뜨릴 때마다 남의 데이터가 샌다 | 앱 계층 권한 검사 |
| 자체 JWT 인증 | Supabase 제거(D104). 토큰 하나면 미들웨어에 네트워크 왕복이 없다 | Supabase Auth |
| Qdrant | 벡터만 따로. **신뢰 경계가 아니다** — 히트 뒤 본문은 RLS로 재조회한다 | pgvector(단일 저장소의 단순함은 포기) |
| Excalidraw | 팬·줌·그리기를 통째로 위임하고 DOM 오버레이를 얹는다 | 캔버스 직접 구현 |
| Upstage | 임베딩·문서 파싱·대화 생성을 한 곳에서. 국내 모델 | OpenAI 계열 |

## 안 쓰는 것

- **Supabase** — D104에서 완전 제거. 인증·DB·스토리지를 자체 구현으로 옮겼다.
- **Whisper / OpenAI** — 대회 규정상 제품 안에서 해외 모델을 못 쓴다(D221).
  강의 파싱·전사는 저장소 밖 오프라인 스크립트가 한다.
- **pgvector** — 벡터는 Qdrant. 표 하나로 합치는 이득보다 검색 튜닝의 자유가
  컸다.
- **상태 관리 라이브러리 전면 도입** — zustand는 **작업공간 상태**에만 쓴다.
  서버 데이터는 react-query가, 캔버스 좌표는 ref가 갖는다(팬/줌마다 React를
  돌리면 화면이 답답해진다, D124).
